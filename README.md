# 🤖 Kwork Auto-Bidder & AI Analyzer

Автоматический мониторинг биржи Kwork, фильтрация заказов, интеллектуальный анализ осуществимости силами AI/разработчика и автоотклик через форму предложения услуг.

---

## 🌟 Ключевые возможности

1. **Работа через реальный профиль браузера (Playwright):**
   - Не вызывает блокировок Cloudflare, так как использует постоянную директорию профиля (`browser_profile/`).
   - Вход в аккаунт требуется выполнить **только один раз** при первом запуске.

2. **Интеллектуальный анализ нейросетью (Gemini, запасная — DeepSeek или любой OpenAI-совместимый API):**
   - Новые карточки отбирает дешёвая модель запасной нейросети, а отклик пишет Gemini — так дневной лимит Gemini тратится только на отклики. Если Google не отвечает или отклонил ключ, отклик пишет запасная нейросеть, а в Telegram приходит предупреждение (и наоборот: если запасная недоступна, отбор делает дешёвая модель Gemini).
   - Смотрит только вкладку «Любимые» на бирже: рубрики выбираются звёздочкой в аккаунте Kwork. Если любимых рубрик не видно (например, слетел вход), бот не разбирает заказы и предупреждает в Telegram.
   - Оценивает осуществимость задачи с учётом её рубрики (парсинг, боты, скрипты, бэкенд, автоматизация, а также тексты, переводы и другие любимые рубрики).
   - Отсекает невыполнимые офлайн-задачи (курьеры, физический труд).
   - Автоматически формирует профессиональный стек технологий (Python, Playwright, Aiogram, BeautifulSoup и др.).

3. **Точное заполнение формы Kwork (согласно скриншоту):**
   - **Описание:** вежливое приветствие, подтверждение понимания функционала из ТЗ, краткий стек технологий, строго от 160 до 1900 символов (требование Kwork: не менее 150 символов).
   - **Стоимость:** желаемый бюджет покупателя (например, "до 3000" ➔ 3000 ₽).
   - **Название заказа:** лаконичное и релевантное название (до 70 символов).
   - **Срок выполнения:** 2 или 3 дня в зависимости от объема задачи.

4. **Защита от нежелательной траты коннектов:**
   - Режим `DRY_RUN = true` (включен по умолчанию) — форма полностью заполняется, сохраняется скриншот в папку `screenshots/`, но кнопка «Предложить» не нажимается.
   - Локальная база данных SQLite (`kwork_bot.db`) гарантирует, что каждый заказ обрабатывается ровно один раз.

## 🚀 Быстрый старт

### Шаг 1. Настройка окружения
1. Скопируйте файл конфигурации:
   ```powershell
   copy .env.example .env
   ```
2. Откройте `.env` и укажите ключи нейросетей — основной Gemini и запасной:
   ```env
   GEMINI_API_KEY=...
   LLM_API_KEY=sk-...
   ```
   *(Ключ Gemini создаётся в [Google AI Studio](https://aistudio.google.com/apikey), ключ DeepSeek — в [DeepSeek Platform](https://platform.deepseek.com/api_keys). Достаточно одного из двух, но с обоими бот продолжит работать, если одна нейросеть откажет.)*

3. На бирже Kwork отметьте звёздочкой любимые рубрики — бот следит только за ними (вкладка «Любимые», `https://kwork.ru/projects?a=1`). Новую рубрику можно отметить в любой момент: бот увидит её заказы со следующей проверки биржи.

### Шаг 2. Первый запуск и авторизация в Kwork
Запустите бота:
```powershell
python main.py
```
- При первом запуске откроется окно Chromium.
- Введите ваши логин и пароль от Kwork (и код подтверждения/2FA, если подключен).
- После успешного входа бот обнаружит авторизацию, сохранит сессию в папку `browser_profile/` и приступит к мониторингу.
- При всех последующих запусках повторный вход **не потребуется**!

## ⚙️ Параметры конфигурации (.env)

| Параметр | По умолчанию | Описание |
|---|---|---|
| `GEMINI_API_KEY` | `""` | Ключ API Gemini — основной нейросети ([Google AI Studio](https://aistudio.google.com/apikey)) |
| `GEMINI_MODEL` | `gemini-3.5-flash` | Основная модель Gemini |
| `GEMINI_FALLBACK_MODELS` | `gemini-3.6-flash,gemini-3.7-flash,gemini-3.5-flash-lite` | Запасные модели Gemini через запятую (перебираются по очереди; лёгкая модель в конце — у неё больше дневной лимит) |
| `GEMINI_SCREEN_MODEL` | `gemini-3.5-flash-lite` | Дешёвая модель Gemini для отбора заказов — когда запасная нейросеть недоступна |
| `GEMINI_PROXY` | `""` | Прокси для запросов к Gemini (необязательно) |
| `GEMINI_BASE_URL` | `""` | Адрес API Gemini (пусто — стандартный адрес Google) |
| `LLM_API_KEY` | `""` | Ключ API запасной нейросети |
| `LLM_MODEL` | `deepseek-v4-pro` | Основная модель запасной нейросети |
| `LLM_FALLBACK_MODELS` | `deepseek-flash` | Запасные модели через запятую |
| `LLM_SCREEN_MODEL` | `deepseek-flash` | Дешёвая модель для отбора новых карточек — спрашивается первой (пусто — отбор только через Gemini) |
| `LLM_BASE_URL` | `https://api.deepseek.com` | Адрес OpenAI-совместимого API |
| `LLM_PROXY` | `""` | Прокси для запросов к запасной нейросети (необязательно) |
| `DATABASE_URL` | `""` | Строка подключения PostgreSQL; пусто — SQLite. Заказы из SQLite переносятся при первом запуске |
| `DRY_RUN` | `true` | `true` — тестовый режим (скриншоты без отправки), `false` — боевой режим |
| `HEADLESS` | `false` | `false` — окно браузера видно на экране, `true` — скрытый режим |
| `CHECK_INTERVAL_MIN` | `60` | Минимальная пауза между проверками биржи (в сек.) |
| `CHECK_INTERVAL_MAX` | `120` | Максимальная пауза между проверками биржи (в сек.) |

## 🧪 Тестирование анализатора

Чтобы протестировать анализ ТЗ, генерацию текстов и работу с базой данных без запуска браузера:
```powershell
python test_analyzer.py
```
Скрипт прогонит три типовые задачи (парсинг интернет-магазина, Telegram-бот и офлайн-расклейку), проверит соблюдение всех лимитов (150+ символов, срок 2-3 дня, название до 70 знаков) и сохранит результаты в тестовую БД.
